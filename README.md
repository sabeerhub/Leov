# LEOV Corporate – Premium SaaS-Grade Corporate Platform

![LEOV Hero Section](https://images.unsplash.com/photo-1486406146926-c627a92ad1ab?q=80&w=1200&auto=format&fit=crop)

## 🎯 The Vision
LEOV is a world-class corporate platform designed with a modern SaaS-inspired aesthetic. Inspired by the design languages of **Stripe, Apple, and Linear**, this website communicates authority, innovation, and trust through a minimal yet high-impact UI/UX.

Built for the African digital frontier, LEOV combines fintech-grade professionalism with cutting-edge motion design.

---

## ✨ Key Features

### 🎞️ Floating Dynamic Brand Cards (Hero)
A premium animated visual system that brings the brand to life.
- **Continuous Motion**: Subtle vertical and horizontal drift using Framer Motion.
- **Parallax Depth**: Cards react to mouse movement with varying intensities based on their Z-axis depth.
- **Interactive Repulsion**: Neighboring cards subtly shift away when a card is hovered, creating a "living ecosystem" feel.
- **Auto-Carousel Layer Shift**: The depth and layout of cards rotate every 5 seconds to maintain visual interest.
- **Responsive Handling**: The complex 3D-like grid transforms into a smooth horizontal swipeable carousel on mobile devices.

### 🎨 Modern UI Design System
- **Typography**: Focused on high-legibility sans-serif fonts (Inter/Satoshi style).
- **Glassmorphism**: Sticky blur navbars and card overlays for a premium, layered feel.
- **Soft UI**: Rounded corners (16–24px), subtle shadows, and high-quality iconography (Lucide).
- **Micro-interactions**: Spring physics on all buttons and interactive elements.

### 🏗️ Fully Featured Sections
- **About LEOV**: Story-driven brand narrative with interactive value cards.
- **Services**: A grid-based showcase of core offerings with hover-lift effects.
- **Projects/Portfolio**: Animated filtering system for case studies.
- **Logo Wall**: Trusted partners section for social proof.
- **Conversion-Optimized Contact**: Sleek, professional form designed for high-ticket lead generation.

## 🛠️ Tech Stack

- **Framework**: [Next.js (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Performance & Quality
- **Lighthouse Ready**: Optimized for speed, accessibility, and SEO.
- **No Layout Shift**: Strict aspect ratios and image placeholders ensure CLS = 0.
- **Responsive**: Pixel-perfect from mobile (320px) to ultra-wide displays.
- **Type-Safe**: 100% TypeScript coverage for a robust development experience.

## 💻 Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/leov/corporate-platform.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
